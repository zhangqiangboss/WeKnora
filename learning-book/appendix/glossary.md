# 附录 B　核心术语表

[返回全书目录](../README.md)

## Agent

让模型在循环中根据当前状态选择下一步动作的应用架构。动作可能是回答、检索知识、调用 API、执行代码或使用 MCP 工具。Agent 不是某一种模型名称。

## BM25

经典关键词相关性算法，综合词频、逆文档频率和文档长度评估文本匹配。擅长错误码、名称和精确术语，与向量检索互补。

## Chat Model

接收角色消息并生成文本或工具调用的模型能力。可以非流式或流式返回。

## Chunk

文档经过解析和切分后形成的知识片段，是检索、引用和上下文构造的基本单位。

## Context Window

模型一次请求能够处理的 Token 总量范围，通常包括系统消息、历史、检索证据、工具定义、当前问题和输出。

## Embedding

将文本、图片等内容映射为浮点向量的过程或模型能力。相近语义通常在向量空间中距离更近。

## EventBus

在应用内部发布和消费事件的机制。WeKnora 用它传递检索阶段、答案增量、引用、完成和错误等运行事件。

## Function Calling / Tool Calling

模型按照工具 Schema 生成结构化调用意图，由应用执行实际工具，再把结果返回模型。模型本身通常不会直接执行函数。

## Human-in-the-loop

在自动流程的高风险或不确定节点暂停，等待人类审批、修改或拒绝后再继续。Agent 中常用于外部写入、删除、发送、支付或权限敏感工具。

## Hallucination

模型生成看似合理但缺乏事实依据、与证据冲突或完全错误的内容，通常译作“幻觉”。

## Groundedness / Faithfulness

生成答案中的事实是否得到给定检索证据支持，常译为“有依据性”或“忠实性”。它不同于答案是否碰巧正确：模型可能依靠参数记忆答对，但没有使用或遵守当前证据。

## Hybrid Search

组合向量语义检索、关键词检索或其他召回方式，再对结果进行归一化、融合和去重。

## Knowledge Base

WeKnora 中组织文档、FAQ、模型、切块和检索配置的业务容器。

## Knowledge

WeKnora 中一份导入的文件、URL 或手工文本对应的知识记录。它属于某个 Knowledge Base。

## LLM

Large Language Model，大语言模型。工程语境中常特指处理消息并生成文本/工具调用的基础模型服务。

## MCP

Model Context Protocol。用于统一 AI 应用与外部工具、资源和提示之间交互的协议。它降低工具接入耦合，但不自动解决权限和可信执行问题。

## Observation

Agent 执行动作后获得的可观察结果，可以是工具数据、业务失败或执行错误。Observation 会进入下一轮上下文，供模型决定继续、换方法或结束。

## MAP

Mean Average Precision，平均准确率均值。它综合一个查询中多个相关结果出现的位置，再对所有查询取平均，适合评估需要召回多份相关证据的检索任务。

## MMR

Maximal Marginal Relevance，最大边际相关性。选择候选时同时奖励查询相关性、惩罚与已选结果的相似性，用于减少 Top-K 中的重复内容。

## MRR

Mean Reciprocal Rank，平均倒数排名。用第一个相关结果排名的倒数衡量检索效果，越早出现相关结果分数越高。

## nDCG

Normalized Discounted Cumulative Gain，归一化折损累积增益。综合相关性等级和排名位置，靠后的相关结果贡献更小。

## Prompt

发送给模型的指令和内容。成熟系统中通常由模板、历史、检索证据、用户输入、工具定义等共同构成，更广义的概念是上下文工程。

## RAG

Retrieval-Augmented Generation，检索增强生成。在生成前动态检索外部知识，并将证据放入模型上下文。

## Precision

准确率。在检索评测中表示返回结果里有多少真正相关，常写为 Precision@K。它与 Recall 形成取舍：结果更少、更严格时 Precision 可能提高，但可能漏掉相关证据。

## Recall

召回。检索系统从大规模数据中找出候选的过程；评测中的召回率描述应该找到的相关内容有多少被找到了。

## ReAct

一种常见 Agent 模式，通过推理、行动和观察结果的循环逐步完成任务。工程实现必须增加终止条件、权限、超时和错误处理。

## Rerank

对第一阶段召回的候选进行更精细的相关性重排。通常输入查询和候选文本，输出新的分数或顺序。

## RRF

Reciprocal Rank Fusion，倒数排名融合。根据候选在多条结果列表中的排名计算融合分，不要求向量分和关键词分处于同一尺度。

## BLEU / ROUGE

通过词或子序列重合比较生成文本与参考文本的自动指标。适合低成本回归，但不能单独证明事实正确、忠于证据或引用有效。

## SSE

Server-Sent Events。服务器通过一个 HTTP 连接持续向浏览器发送事件。WeKnora 用它承载答案增量、进度、引用和完成状态。

## Temperature

影响模型采样分布的参数。通常更高会增加多样性，也可能降低稳定性；具体范围和行为依供应商而异。

## Token

模型处理文本时使用的离散单位，不严格等于字或单词。输入、输出、上下文限制和计费通常都以 Token 计算。

## Tool Call

模型生成的一次结构化工具调用意图，通常包含调用 ID、工具名称和 JSON 参数。它不是已执行操作；应用仍需解析、校验、授权并调用真实工具。

## Tool Schema

描述工具名称、用途和参数结构的模型接口契约，通常使用 JSON Schema。它帮助模型选择工具和生成参数，但不能替代对象级权限、业务规则与执行安全检查。

## Top-K

只保留排序最靠前的 K 个结果。RAG 中可能分别存在召回 Top-N、Rerank Top-K 和最终上下文 Top-K，含义不要混淆。

## Vector Database / Vector Store

支持存储向量并执行近邻搜索的数据库或检索后端。它可能是专用向量数据库，也可能是带向量扩展的 PostgreSQL、SQLite 或搜索引擎。

## VLM

Vision-Language Model，视觉语言模型。能够联合处理图片与文本，用于图片理解、OCR 后校正、说明生成或多模态问答。
